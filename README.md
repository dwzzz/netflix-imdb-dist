## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或 [Violentmonkey](https://violentmonkey.github.io/)。
2. 安装 `netflix-imdb.user.js`。
3. 用上面的邀请链接注册，拿到个人 API key。
4. 打开 Netflix，把 API key 粘贴到脚本的 Token 输入框。

## 反馈

我对目前 Netflix → IMDb / 豆瓣的解析能力还没有完全放心。电影、剧集、季度和整剧之间有不少边角情况，这也是我把它分享出来的一点小心思。

如果遇到明显错配、该有结果却一直没有、豆瓣链接错误，或任何看起来奇怪的情况，欢迎开 [Issue](https://github.com/dwzzz/netflix-imdb-dist/issues)。真实样本会很有助于我继续完善解析。

## 数据

脚本会向 `ratings.op13.uk` 发送作品 ID；详情匹配时可能额外发送片名、年份、类型和语言。
为了避免 API key 滥用，还会上传你浏览器的 IP 和 User Agent。但仅保留最近 30 天，毕竟个人服务器磁盘寸土寸金。
本项目不是 Netflix、IMDb 或豆瓣官方产品。

### 评分与查询状态

| 显示文字 | 含义 |
| --- | --- |
| `IMDb 8.7`（分数示例） | 已取得对应作品的 IMDb 评分，满分为 10 分。 |
| `· 整剧`（追加在角标后） | 当前展示的是父剧集整体的 IMDb 评分，不是当前 Netflix 分季或单集的评分。 |
| `IMDb 暂未获取评分` | 已确认作品身份，但当前返回的数据中没有可用的 IMDb 分数，不代表评分为零。 |
| `豆瓣` | 在完整详情中打开已匹配的豆瓣条目，仅提供跳转，不显示豆瓣评分。 |
| `IMDb 等待查询` | 正在等待本地排队或服务受理，轮到后会自动继续，当前可见作品优先。 |
| `IMDb 查询中` | 请求正在查询、等待服务器处理或自动轮询结果，通常无需点击。 |
| `IMDb 等待数据源` | 上游数据源处于冷却期，脚本会在允许的时间继续查询。 |
| `IMDb 自动重试中` | 此作品已连续遇到至少两次临时故障，脚本正在按等待规则重试。 |

| `IMDb 暂时不可用` / `IMDb 暂时不可用 · 点击重试` | 本轮遇到临时故障且不再自动重试，可展开详情手动重试。 |
| `IMDb 查询失败` | 本轮查询因未被归为可重试状态的错误而结束，可悬停或查看最近错误详情了解原因。 |

### 作品匹配状态

| 显示文字 | 含义 |
| --- | --- |
| `IMDb 待匹配` | 尚未确认 Netflix 与 IMDb 的对应关系，可展开详情继续匹配或手动输入 IMDb 编号。 |
| `IMDb 详情匹配中` | 正在用当前详情中的片名、年份、类型等信息寻找对应作品。 |
| `IMDb 仍在匹配` | 详情匹配尚未完成且本轮自动查询已停止，可稍后手动重新匹配。 |
| `IMDb 匹配超时，请手动重试` | 本轮详情匹配的等待或查询预算已用完，需要手动重试。 |
| `IMDb 请选择作品` | 当前有候选作品需要你确认，不能把候选直接当作已匹配结果。 |
| `IMDb 暂无可选作品` | 仍未确认作品身份，且这次没有可供选择的候选，可重新匹配或手动输入 IMDb。 |
| `IMDb 详情不足` | 当前页面提供的信息不足以完成名称匹配，可打开完整详情或手动输入 IMDb。 |
| `IMDb 名称匹配未启用` | 服务器没有启用名称匹配能力，仍可尝试已有编号对应关系或手动输入 IMDb。 |
| `IMDb 不支持此层级` | 请求涉及当前匹配接口不支持的作品层级，例如无法直接按单季或单集处理。 |
| `IMDb 匹配失败` | 详情匹配遇到了错误或未能处理的结果，可查看悬停说明后重新匹配。 |

海报上的普通评分不会接管 Netflix 原有点击行为；需要人工选择的海报角标可以点击，详情中的已确认评分可以打开 IMDb。已有评分可用时，脚本也可能保留分数，只在悬停提示中说明正在更新或更新失败。
